
# perTheater

perTheater is a movie collection website that allows users to save, organize, and manage information about movies they enjoy watching. It provides a personal space where users can keep track of their favorite movies and store important details about them for future reference.

The application is built using Node.js, Express.js, MongoDB, EJS, and JavaScript.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- EJS
- JavaScript
